# 진도판

2027년 변리사 1차 학습 진도 대시보드. 정적 페이지 하나로 동작한다.

**→ https://dangchame.github.io/study-plan/**

## 무엇인가

계획 계산 로직이 페이지 안에 들어 있다. 진도(강수·페이지)를 입력하면
증량 램프 · 회독 6주 주기 · 하루 총합이 브라우저에서 다시 계산된다.
서버도 빌드도 없다.

## 파일

| 파일 | 역할 |
|------|------|
| `index.html` | 배포본. 이 파일 하나가 사이트 전부다 |
| `plan.tpl.html` | 원본 템플릿. `/*INVENTORY*/` 자리에 강의 데이터가 들어간다 |
| `lectures.json` | 13개 강좌 372강의 강별 시간·예습 단가 |

## 진도 저장

- 진도는 **브라우저(localStorage)** 에 저장된다.
- 다른 기기로 옮기려면 **«이 진도로 링크 복사»** 를 눌러 그 주소를 열면 된다.
  진도가 URL 해시에 들어 있어 주소만 옮기면 그대로 이어진다.

## 다시 빌드하기

`plan.tpl.html`의 `/*INVENTORY*/`를 `lectures.json` 내용으로 치환한 뒤
`<!doctype html>` 문서로 감싸면 `index.html`이 된다.

```
python3 build.py
```

## 계산 규칙

- 주 5일(월-금) 공부 + 2일 휴식
- 강의는 2배속. −5분 보정은 민사소송법 한정
- 예습: 화학 기출·객관식 20분/강(실측) · 물리 기출 30분/강(가정) · 생물·지구 10분/강
- 교재: **민법연습장** 3-275p · **특허연습장** 2-362p (둘 다 해설 없이 문제만)
- 회독 속도: 민법연습장 **6.7p/h** · 특허연습장 **17.2p/h**
  - 연습장은 구 교재에서 **해설만 뺀 판**이라 총 소요 시간이 보존된다 → 압축비로 환산
  - 민법 1024p ÷ 273p = 3.75배 → 25p/h(실측) ÷ 3.75 = 6.7p/h
  - 특허 630p ÷ 361p = 1.75배 → 30p/h(미측정) ÷ 1.75 = 17.2p/h
- `*` 표시는 미개강 강의의 추정치
